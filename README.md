# ahk-quick-keytouch

AutoHotkey を使って、ホームポジションから手をあまり動かさずに操作するためのショートカット集。

- 対象: Windows ＋ 日本語（JIS）配列キーボード（無変換・変換キーを使う）
- 動作環境: AutoHotkey **v1.1**（v1.1.37.01 で確認。v2 では動かない）
- 本体: `quick-keytouch.ahk`

## セットアップ

1. [AutoHotkey](https://www.autohotkey.com/) v1.1 をインストールする
2. このリポジトリを好きな場所に clone する（スクリプトはリポジトリ内のファイルをそのまま使う）
3. ログオン時に自動で起動するよう登録する（下のどちらか）

### 通常権限で起動する

スタートアップフォルダに、リポジトリ内の `quick-keytouch.ahk` へのショートカットを作る。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-startup.ps1
```

### 管理者として起動する（推奨）

通常権限だと、タスクマネージャーや管理者のターミナルなど**管理者として動いているウィンドウにフォーカスがある間はショートカットが効かない**（Windows の仕様）。
管理者として起動すればこれを避けられる。

スタートアップフォルダのショートカットを「管理者として実行」にしても、Windows はログオン時の起動を止めてしまう。
そのため、タスクスケジューラに「ログオン時に最上位の特権で実行」するタスクとして登録する（UAC の確認も出ない）。

**管理者として開いた PowerShell** で実行する:

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-startup.ps1 -Admin
```

二重起動を防ぐため、通常権限用のショートカットがあれば削除される。

> [!WARNING]
> 管理者で起動すると、`quick-keytouch.ahk` に書かれた内容は次のログオン時から管理者の権限で動く。
> このファイルは普通の権限でも書き換えられるので、知らない変更が入っていないか（`git diff` など）を確認してから使うこと。

登録されたタスクは「タスク スケジューラ」（`taskschd.msc`）のライブラリ直下に `ahk-quick-keytouch` という名前で表示される。そこから確認・無効化・削除もできる。

### 登録を解除する

```powershell
powershell -ExecutionPolicy Bypass -File .\setup-startup.ps1 -Uninstall
```

タスクも削除する場合は管理者の PowerShell で実行する。

### スクリプトを更新したとき

登録先はリポジトリ内のファイルなので、`git pull` や編集のあとは再読み込み（`Ctrl + Alt + R` か、タスクトレイのアイコン → Reload This Script）するだけでよい。

## 操作方法

基本は **無変換キー** を押しながら別のキーを押す。

### カーソル移動・選択

| キー | 動作 |
| --- | --- |
| 無変換 ＋ `i` / `k` / `j` / `l` | ↑ / ↓ / ← / → |
| 上の操作 ＋ Shift / Ctrl / Shift+Ctrl | Shift+矢印（選択）/ Ctrl+矢印（単語移動）/ Shift+Ctrl+矢印 |
| 無変換 ＋ `;` | Home（Shift を足すと Shift+Home） |
| 無変換 ＋ `:` | End（Shift を足すと Shift+End） |
| 無変換 ＋ `.` | PageUp |
| 無変換 ＋ `/` | PageDown |
| Alt ＋ `i` / `k` | Alt+↑ / Alt+↓（Shift・Ctrl を足した組み合わせも可。VS Code の行移動など） |

### 編集

| キー | 動作 |
| --- | --- |
| 無変換 ＋ `m` | Enter（Shift / Ctrl / Shift+Ctrl を足した組み合わせも可） |
| 無変換 ＋ `p` | Backspace |
| 無変換 ＋ `[` | Delete |
| 無変換 ＋ `@` | Insert |
| 無変換 ＋ `e` | Esc |
| 無変換 ＋ `a` | すべて選択（Ctrl+A） |
| 無変換 ＋ `n` | コピー（Ctrl+C） |
| 無変換 ＋ `x` | 切り取り（Ctrl+X） |
| 無変換 ＋ `,` | 貼り付け（Ctrl+V） |
| 無変換 ＋ `u` | 元に戻す（Ctrl+Z） |
| 無変換 ＋ `y` | やり直し（Ctrl+Y） |
| 無変換 ＋ `s` | 保存（Ctrl+S） |
| 無変換 ＋ `h` | 実行（F5） |
| 無変換 ＋ `o` | 半角/全角の切り替え |

### 記号

| キー | 動作 |
| --- | --- |
| 無変換 ＋ Shift ＋ `u` | `'`（7 が遠いため） |
| 変換 ＋ Shift ＋ `t` | `&`（6 が遠いため） |

### 変換キー

| キー | 動作 |
| --- | --- |
| 変換 | Shift として働く |

### 仮想デスクトップ

| キー | 動作 |
| --- | --- |
| 左Shift ＋ 右Shift ＋ `a` | 左のデスクトップへ（Win+Ctrl+←） |
| 左Shift ＋ 右Shift ＋ `d` | 右のデスクトップへ（Win+Ctrl+→） |

### テンキーモード

**英数（CapsLock）キー**を押すたびにオン・オフが切り替わる。オンの間は次のように入力される。

| キー | 入力 | キー | 入力 | キー | 入力 |
| --- | --- | --- | --- | --- | --- |
| `7` | 7 | `8` | 8 | `9` | 9 |
| `u` | 4 | `i` | 5 | `o` | 6 |
| `j` | 1 | `k` | 2 | `l` | 3 |
| `m` / `0` | 0 | `:` | `*` | `;` | `+` |
| `p` | Backspace | `w` `a` `s` `d` | ↑ ← ↓ → | | |

`, - . / ^ [ ]` や Shift を足した `( ) < = > ~` は、そのままの文字が入力される。

### 困ったとき

| キー | 動作 |
| --- | --- |
| Ctrl ＋ Alt ＋ `R` | Shift・Ctrl・Alt・Win を離してからスクリプトを再読み込みする |

ショートカットが急に効かなくなったときに使う（キーの押しっぱなし状態がずれたときや、負荷が高くて Windows にキー監視を外されたとき）。
このキーは、キー監視が外れていても効く方法で登録してある。
